# Optimal Control Examples

Interactive examples of basic optimal control (LQR and LQ-MPC) written with [marimo](https://marimo.io/).

## Getting Started

Easiest way to run the examples is online in [molab](https://molab.marimo.io/notebooks/nb_joodKAy8xSto8XhSkqUvjJ). Press "Run it now" on top of the screen and then "Run all stale cells" (`ctrl+shift+R`) in the bottom right corner.

The examples can be also run locally. To do so, first install dependencies with
```
uv sync
```
then run the notebook
```
marimo run birotor_stabilization.py
```
